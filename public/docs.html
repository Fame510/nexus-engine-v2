API docs

Run docker compose up --build, then submit jobs with your API key.

Submit a job

curl -X POST http://localhost:3000/v1/jobs \
 -H 'Authorization: Bearer dev-key-change-me' \
 -H 'Content-Type: application/json' \
 -d '{"url":"https://example.com","engine":"playwright","mode":"headless","extract":{"schema":{"title":{"selector":"h1"}}},"artifacts":{"html":true,"screenshot":true}}'

Lifecycle

GET /v1/jobs/:id returns queued, running, completed, failed, or cancelled state. GET /v1/jobs/:id/events returns the durable event trail. Artifacts are available through /v1/jobs/:id/artifacts/:name.

Plans

Community is for self-hosting. Starter and Growth are hosted plans. The SaaS control plane exposes GET /v1/plans, GET /v1/account, and POST /v1/account/api-keys.
